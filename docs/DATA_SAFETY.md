# Declaração de Segurança de Dados

Use estas respostas somente enquanto a versão publicada continuar igual ao código deste repositório:

- Coleta ou compartilhamento de dados: **não**.
- Dados criptografados em trânsito: **não se aplica**, pois o jogo não transmite dados.
- Exclusão de conta: **não se aplica**, pois não existe conta de usuário.
- Anúncios: **não**.
- Compras no aplicativo: **não**.
- Público-alvo recomendado: público geral; confirme a faixa etária na classificação de conteúdo da Play Console.
- Permissões sensíveis: **nenhuma**.

O recorde fica apenas no armazenamento local do WebView e é apagado quando os dados do aplicativo são removidos.
